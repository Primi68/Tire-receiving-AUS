# Tire Receiving 0.1.1 — 목록 선택과 타이어 무늬

- 게시일: 2026-11-10
- 태그: `v0.1.1-mvp`
- APK: `Tire-Receiving-0.1.1-preview.apk`

## 설치 정보

| 항목 | 값 |
| --- | --- |
| Package | `com.primi.tirereceiving` |
| Version | `0.1.1` (`versionCode 2`) |
| 최소 Android | Android 8.0 / API 26 |
| 대상 Android SDK | 35 |

0.1.0과 같은 package와 고정 서명 인증서를 사용하므로 기존 앱 위에 업데이트할 수 있습니다. 업데이트해도 기기에 저장된 타이어 마스터와 검수 기록은 유지됩니다. 업데이트 전에는 **데이터 관리 → 백업 내보내기**를 권장합니다.

## 변경 내용

- **검수 시작**을 누르면 검색창에 자동으로 커서를 두지 않고 14개 타이어 목록을 바로 표시합니다.
- 키보드는 작업자가 검색창을 직접 눌렀을 때만 열립니다.
- 검수 선택 목록과 Tire presets 카드에 위에서 아래로 읽는 4줄 타이어 무늬 아이콘을 표시합니다.
- Tire presets 편집 화면에서 네 줄을 각각 없음·빨강·노랑·초록·흰색·파랑·주황·보라 중 하나로 설정할 수 있습니다.
- 초기 MYP 무늬는 빨강·빨강·없음·없음이고, Bridgestone은 노랑·없음·없음·없음입니다. 나머지 초기 타이어는 미설정입니다.
- 기존 로컬 데이터와 0.1.0 백업에는 무늬 필드가 없어도 자동 보완해 그대로 사용할 수 있습니다.

## 검증

- `npm test`, `npm run check`
- Chromium 393×852 화면에서 검색 자동 포커스 없음, 14개 목록, MYP·Bridgestone 초기 무늬, 네 줄 편집 미리보기 확인
- Android debug/release 빌드와 lint
- APK package, version, min/target SDK, 요청 권한 없음 확인
- APK Signature Scheme v2와 고정 인증서 SHA-256 확인
- 게시된 APK, `SHA256SUMS.txt`, `SIGNING-CERT-SHA256.txt` 재다운로드 검증

실제 Android 휴대전화에서의 설치와 키보드 동작은 이 릴리스의 자동 검증 결과에 포함하지 않습니다. 실제 기기 점검 항목은 [검증 기준](../VERIFICATION.md)에 남겨 두었습니다.
