# Tire Receiving 0.1.3 — Android 확인창 수정

- 게시일: 2026-11-11
- 태그: `v0.1.3-mvp`
- APK: `Tire-Receiving-0.1.3-preview.apk`

## 설치 정보

| 항목 | 값 |
| --- | --- |
| Package | `com.primi.tirereceiving` |
| Version | `0.1.3` (`versionCode 4`) |
| 최소 Android | Android 8.0 / API 26 |
| 대상 Android SDK | 35 |

0.1.2와 같은 package와 고정 서명 인증서를 사용하므로 기존 앱 위에 업데이트할 수 있습니다. 업데이트해도 기기에 저장된 타이어 마스터와 검수 기록은 유지됩니다. 업데이트 전에는 **데이터 관리 → 백업 내보내기**를 권장합니다.

## 수정 내용

- Android APK의 수량 확인 단계에서 닫기(X)를 눌러도 반응하지 않던 문제를 수정했습니다.
- 저장하지 않은 검수를 닫을 때 Android 확인창에서 **확인** 또는 **취소**를 선택할 수 있습니다.
- 같은 확인창 기능을 사용하는 프리셋 삭제, 검수 기록 삭제, JSON 백업 복원도 Android에서 정상 처리되도록 수정했습니다.
- 수량 계산, 타이어 무늬, 랙 프리셋과 기존 로컬 데이터 구조는 변경하지 않았습니다.

## 검증

- `npm test`, `npm run check`
- Chromium 393×852에서 수량 확인 X의 취소·확인 동작 확인
- Android WebView의 `WebChromeClient.onJsConfirm`, 승인·취소 처리 정적 검사
- Android debug/release 빌드와 lint
- APK package, version, min/target SDK, 요청 권한 없음 확인
- APK Signature Scheme v2와 고정 인증서 SHA-256 확인
- 게시된 APK, `SHA256SUMS.txt`, `SIGNING-CERT-SHA256.txt` 재다운로드 검증

실제 Android 휴대전화에서 확인창을 누르는 검증은 이 릴리스의 자동 검증 결과에 포함하지 않습니다. 실제 기기 점검 항목은 [검증 기준](../VERIFICATION.md)에 남겨 두었습니다.
