## 간결한 오늘 화면

- 큰 `TODAY WORKLIST` 안내 카드와 다섯 개 통계 카드를 제거했습니다.
- 오늘 화면 상단에는 `1 / 2건 검수 · 대기 1건`처럼 현재 진행 상황만 표시합니다.

## 검수 통계

- 우측 상단 메뉴를 **검수 통계 · 데이터**로 확장했습니다.
- 지금까지 저장한 검수 기록 수를 표시합니다.
- 검수 기록이 있는 고유 날짜를 계산해 실제 리시빙 일수를 표시합니다.
- 누적 실측 수량과 오늘 실측 수량을 표시합니다.
- 큰 수량도 `5K`로 줄이지 않고 `5,850 EA`처럼 정확한 값으로 표시합니다.
