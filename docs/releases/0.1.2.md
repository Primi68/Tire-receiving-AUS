# Tire Receiving 0.1.2 — 상세 타이어 무늬

- 게시일: 2026-11-10
- 태그: `v0.1.2-mvp`
- APK: `Tire-Receiving-0.1.2-preview.apk`

## 설치 정보

| 항목 | 값 |
| --- | --- |
| Package | `com.primi.tirereceiving` |
| Version | `0.1.2` (`versionCode 3`) |
| 최소 Android | Android 8.0 / API 26 |
| 대상 Android SDK | 35 |

0.1.1과 같은 package와 고정 서명 인증서를 사용하므로 기존 앱 위에 업데이트할 수 있습니다. 업데이트해도 기기에 저장된 타이어 마스터와 검수 기록은 유지됩니다. 업데이트 전에는 **데이터 관리 → 백업 내보내기**를 권장합니다.

## 변경 내용

- 14개 초기 타이어의 실제 식별 무늬를 위에서 아래 네 줄로 확장했습니다.
- 다홍·하늘·갈색과 노랑·주황 점선을 추가했습니다.
- MYP와 CT P는 1·2번째 줄, E80 Continental Rear는 2·3번째 줄, W68 Front는 3·4번째 줄을 가까이 표시합니다.
- Goodyear 18/20은 색선 없이 회색 트레드 패턴만 표시합니다.
- Tire presets에서 각 줄의 색·점선과 가까운 줄 조합을 수정할 수 있습니다.
- 0.1.1에서 사용자가 직접 바꾼 색 배열은 보존하고, 초기값 그대로인 타이어만 새 기본 무늬로 보완합니다.
- 0.1.0 백업처럼 무늬 정보가 없는 데이터도 0.1.2 기본값으로 자동 보완합니다.

## 검증

- `npm test`, `npm run check`
- Chromium 393×852 화면에서 전체 초기 무늬, 점선, 가까운 줄 간격과 편집 미리보기 확인
- 0.1.1 초기 데이터의 새 기본값 마이그레이션과 사용자 수정 무늬 보존 확인
- Android debug/release 빌드와 lint
- APK package, version, min/target SDK, 요청 권한 없음 확인
- APK Signature Scheme v2와 고정 인증서 SHA-256 확인
- 게시된 APK, `SHA256SUMS.txt`, `SIGNING-CERT-SHA256.txt` 재다운로드 검증

실제 Android 휴대전화에서의 설치와 화면 표시는 이 릴리스의 자동 검증 결과에 포함하지 않습니다. 실제 기기 점검 항목은 [검증 기준](../VERIFICATION.md)에 남겨 두었습니다.
