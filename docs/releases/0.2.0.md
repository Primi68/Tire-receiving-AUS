# Tire Receiving 0.2.0

## 오늘 검수 목록

- **타이어 추가**에서 오늘 확인할 타이어를 먼저 고를 수 있습니다.
- 같은 타이어도 `+`를 여러 번 눌러 필요한 수만큼 추가할 수 있습니다.
- 목록 작성 단계에서는 현장에서 구분할 수 없는 Dock·Trailer 번호를 요구하지 않습니다.
- 대기 항목을 누르면 타이어 선택 화면을 거치지 않고 수량 확인으로 바로 이동합니다.
- 완료 기록을 삭제하면 연결된 목록 항목은 다시 대기 상태로 돌아갑니다.

## 오늘과 날짜별 기록

- 오늘 화면에 전체·대기·완료·확인 필요 건수와 총 실측 수량을 표시합니다.
- 오늘의 대기 항목과 완료 기록을 최근 5건 제한 없이 모두 표시합니다.
- 지난 기록은 날짜별로 묶고 건수, 완료, 확인 필요와 총 실측 수량을 함께 표시합니다.

## 수량과 타이어 띠

- `16 × 4 × 9 + 52`에서 랙당 적재량 `16`과 4랙 묶음 수 `9`를 강조합니다.
- 고정된 2×2 랙 수 `4`는 보조 값으로 표시합니다.
- 검수 저장 시 타이어 띠 색상과 줄 간격을 함께 저장해 오늘 화면, 기록 목록과 상세 화면에 표시합니다.
- 과거 기록에 띠 스냅샷이 없으면 현재 타이어 프리셋의 띠를 사용합니다.
- HK Performance Front 21"의 맨 위 띠 기본값을 핑크로 변경했습니다.

## 데이터 호환

- 기존 0.1.x 프리셋과 검수 기록은 그대로 사용합니다.
- JSON 백업에 날짜별 검수 목록을 추가했습니다.
- 0.1.x 백업을 복원하면 검수 목록만 빈 상태로 시작하고 기존 프리셋과 기록은 복원됩니다.
