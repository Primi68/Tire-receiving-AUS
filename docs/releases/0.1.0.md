## 이번 버전

노트 앱과 계산기로 나뉘어 있던 타이어 언로딩 확인을 하나의 현장 흐름으로 만들었습니다. 타이어와 Blue/Orange 랙을 선택하면 정상 트레일러 수량을 기준으로 2×2 랙 계산식이 제안되고, 작업자는 Floor의 실제 적재와 다른 부분만 수정해 기록할 수 있습니다.

## 수량 검수

- 핵심 식: `랙당 적재량 × 4 × 묶음 수 + 추가 수량`
- 예상 수량에서 묶음 수와 추가 수량 자동 제안
- Blue/Orange 색상별 랙당 적재량 프리셋
- 예상 수량, 실제 수량, 차이 즉시 표시
- 랙당 적재량·묶음·추가 수량 수정
- 랙 계산이 어려운 경우 실측 총수량 직접 입력
- 현장에서 바꾼 랙당 적재량을 해당 색상 프리셋으로 저장

## 검수 기록

- 완료, 검수 중, Pending, 부분 입고 상태
- 검수 날짜, Dock, Trailer, 받은 수량, 남은 수량, 메모
- 타이어 이름·Dock·Trailer·메모 검색
- 완료·차이 있음·Pending·부분 입고 필터
- 기록 상세, 한 줄 복사, 수정, 삭제
- 오늘 완료 건수, 확인 필요 건수, 실제 수량 합계와 최근 기록

## 로컬 데이터와 백업

- 타이어 마스터와 검수 기록을 기기 로컬에 저장
- 전체 데이터를 날짜가 포함된 JSON 파일로 내보내기
- Android 시스템 문서 선택기로 저장 위치 선택
- JSON 구조를 검사하고 사용자 확인 후 전체 복원
- 잘못된 백업은 현재 데이터를 교체하지 않음
- Android에서 최대 20MB 백업 파일 처리

APK와 웹 앱은 자동 동기화하지 않습니다. 앱 삭제, 앱 데이터 지우기, 기기 교체 전에 JSON을 내보내야 합니다.

## Android 앱

- `dist/` 웹 앱을 APK assets로 직접 포함
- 앱 내부 가상 HTTPS 호스트에서 오프라인 실행
- Android Manifest에 `INTERNET` 권한 없음
- 외부 URL 이동, cleartext traffic, WebView 파일/content 직접 접근 차단
- 시스템 앱 백업 비활성화
- Android 파일 선택기와 클립보드 연동
- Android 뒤로 가기로 열린 sheet 닫기, Today 이동, 앱 종료 순서 처리
- 고정 인증서가 없거나 다르면 release 빌드·검증 실패
