# Tire Receiving 데이터 및 개인정보

기준 버전: **0.1.2**

## 데이터 처리 원칙

Tire Receiving 0.1.2는 계정이나 서버 데이터베이스를 사용하지 않습니다. 타이어 마스터와 검수 기록은 앱을 실행한 기기 또는 브라우저의 로컬 저장소에 남습니다. 자동 업로드와 여러 기기 동기화 기능은 없습니다.

## 저장되는 정보

### 타이어 마스터

- 타이어 이름과 검색 별칭
- 정상 트레일러 예상 수량
- 기본 랙 색상
- Blue/Orange 프리셋 사용 여부와 랙당 적재량
- 위에서 아래 4줄 타이어 무늬 색상·점선과 가까운 줄 간격

### 검수 기록

- 검수 날짜와 생성·수정 시각
- 타이어 이름과 랙 색상
- 랙당 적재량, 묶음 수, 추가 수량, 직접 실측 수량
- 예상 수량, 실제 수량, 차이, 계산식
- 완료·검수 중·Pending·부분 입고 상태
- Dock, Trailer, 부분 입고 수량과 남은 수량
- 사용자가 입력한 메모

이 필드에는 현장 운영 정보가 포함될 수 있습니다. 메모에 개인 이름, 연락처, 계정, 비밀번호 같은 불필요한 개인정보를 입력하지 않습니다.

## 저장 위치

| 환경 | 위치 | 자동 동기화 |
| --- | --- | --- |
| Android APK | 앱 전용 WebView DOM storage | 없음 |
| 웹 앱 | 현재 브라우저 프로필의 사이트별 Local Storage | 없음 |
| JSON 백업 | 사용자가 Android 문서 선택기 또는 브라우저 다운로드에서 고른 위치 | 없음 |

APK와 웹 앱은 별도 저장소를 사용합니다. 같은 기기에서도 한쪽의 기록이 다른 쪽에 자동으로 나타나지 않습니다.

Android Manifest는 시스템 앱 백업을 `android:allowBackup="false"`로 비활성화합니다. 앱 삭제나 앱 데이터 지우기는 APK의 로컬 기록을 삭제할 수 있습니다. 브라우저 사이트 데이터 삭제도 웹 기록을 삭제할 수 있습니다.

## 네트워크와 권한

Android APK:

- `INTERNET` 권한을 선언하지 않습니다.
- APK에 포함된 `dist/` 정적 파일만 앱 내부 가상 HTTPS 호스트에서 읽습니다.
- 외부 URL 이동을 차단합니다.
- cleartext traffic을 허용하지 않습니다.
- WebView의 직접 파일 접근과 content 접근을 비활성화합니다.
- 카메라, 마이크, 위치, 연락처, 전화, 알림 권한을 요청하지 않습니다.

웹 버전은 사이트를 처음 열고 새 배포를 받기 위해 네트워크를 사용합니다. 호스팅 서비스와 브라우저의 일반적인 접속 로그 정책은 APK의 로컬 저장 정책과 별개입니다.

## 사용자가 시작하는 외부 동작

앱은 다음 동작을 사용자가 눌렀을 때만 실행합니다.

- **기록 복사**: 선택한 한 줄 요약을 운영체제 클립보드에 넣습니다. 클립보드 내용은 다른 앱이 접근할 수 있으므로 붙여넣기가 끝나면 민감한 값이 남지 않게 관리합니다.
- **백업 내보내기**: 전체 타이어 마스터와 기록을 JSON으로 만들고 사용자가 고른 문서 위치에 저장합니다.
- **백업 복원**: 사용자가 고른 JSON 파일을 최대 20MB까지 읽고, 구조를 검증한 뒤 확인을 받아 현재 로컬 데이터와 교체합니다.

앱은 선택한 폴더 전체를 훑거나 다른 문서를 임의로 읽지 않습니다.

## 백업 파일 관리

백업 JSON은 암호화된 파일 형식이 아닙니다. 파일을 가진 사람은 내용을 읽을 수 있습니다.

- 회사가 승인한 저장 위치만 사용합니다.
- 개인 메신저, 공개 링크, 이슈, PR, 소스 저장소에 올리지 않습니다.
- 기기 교체나 복원 확인이 끝난 임시 사본은 운영 정책에 따라 정리합니다.
- 파일을 공유해야 한다면 필요한 담당자와 최소 범위로 공유합니다.
- 복원 전 현재 데이터도 별도로 내보내 덮어쓰기 실수를 줄입니다.

## 저장소에 넣지 않는 정보

- 실제 Trailer/Dock 기록이 들어간 JSON 백업
- 실제 현장 메모, 사진, 스크린샷
- Android release keystore
- keystore 비밀번호와 base64 문자열
- GitHub secret 또는 토큰
- 임시 서명 파일과 복원용 파일

예제나 테스트 fixture가 필요하면 실제 기록과 무관한 가상 값을 사용합니다.

## Release 서명 정보

Release APK의 개인 키와 비밀번호는 GitHub Actions secret 또는 승인된 별도 보관소에서 관리합니다. 저장소에는 허용된 공개 인증서의 SHA-256 지문만 남깁니다. 인증서 지문은 APK 출처 확인용이며 개인 키가 아닙니다.

## 데이터 삭제

- 개별 검수 기록: Records에서 기록을 열고 삭제
- 타이어 마스터: Tire presets에서 해당 타이어를 열고 삭제
- 전체 APK 데이터: 필요한 JSON 백업 후 Android 설정에서 앱 데이터 삭제 또는 앱 제거
- 전체 웹 데이터: 필요한 JSON 백업 후 브라우저의 해당 사이트 데이터 삭제
- 내보낸 JSON: 파일 앱 또는 저장 서비스에서 사용자가 직접 삭제

타이어 마스터를 삭제해도 이미 저장된 과거 검수 기록은 자동 삭제되지 않습니다.

## 범위 변경 시 검토

로그인, 서버 동기화, schedule 연동, 분석 도구, 오류 보고, 카메라/OCR, 위치 기능을 추가하기 전에는 이 문서와 권한, 보존 기간, 접근 통제를 먼저 갱신해야 합니다.
